1 · B15 Import replaces everythingdata loss

BeforePick a file → all data replaced, no question. An older backup with no inventory: 784 items → 0. A backup with no people: every button gone.
AfterReplace all data?This file: 0 items, 1 person. Your app: 784 items, 5 people.CancelReplaceFiles without staff or stock are refused.
Why first: once the real data leaves the page (step 2), Import is how your stock gets in.

2 · B9 Real data on a public pageprivacy

BeforeAnyone opening the link sees 902 stock lines and 5 real staff names.
AfterThe page opens empty: "No stock on this device — Load stock file". Your data comes from a backup file kept off GitHub. Wiping the old copies from GitHub's history only with your separate OK (Q1).

3 · B3 New version wipes datadata loss

BeforeA count of 4242 → after an update 1000 again; stock takes gone.
AfterUpdates keep your data and only add missing fields. Test: count 4242, update, still 4242.

AfterCouldn't save. Export a backup now. stays on screen until a save works again.
