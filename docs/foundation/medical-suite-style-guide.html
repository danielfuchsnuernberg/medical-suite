Medical Suite — Style Guide

Graphite Indigo v1.0 · tokens.css

The base reference for every tool in the Suite and for the standalone Dispatch app. All values live in tokens.css — define a color or size there once, and reference it everywhere with var(--token). Never hard-code a hex.

Foundations

Color

Neutral light grays carry the interface; indigo is reserved for actions and active state. Semantic colors are for status only — staff availability, stock levels, patient flags.

Typography

Inter is the canonical UI face, falling back to the system sans so prototypes render instantly. A monospace face is reserved for IDs, codes, and log timestamps — anything machine-generated.
