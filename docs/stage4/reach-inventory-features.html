Demo order

The demos come in 4 batches, foundation first

Each batch is one page of clickable demos built on the June screens, with made-up data and a short "how to use it" per feature. You approve a batch before the next one starts. The foundation comes first because every other screen stands on it: signing in, the menu, and working without internet.

F17 and F18 get no demo now. Each one gets its own run through the stages when its time comes: F17 when EDP and the server are ready, F18 when patients come in.

Question Q12 · the one open question

What goes into the first release?

What it's about

The first release is the first version the nurses and doctors install on their Macs and Windows PCs and do real counts with. Everything on this list gets demoed and built. This question only decides what they get on day one and what follows in the second version.

Why it matters

More in release 1 means they get it later. The roster is the tricky part. You said EDP's dispatcher needs it, but EDP can only read it once the shared server and EDP's side exist. Before then it's a duty plan for the medical team only. Leave out the people side and the app has a sign-in but no Staff screens. The June app had them.
